# Документация (на русском)

Пошаговые инструкции по превращению Raspberry Pi 1 в принт-сервер
для HP LaserJet 1020:

1. **[01-flash-sd.md](01-flash-sd.md)** — запись Raspberry Pi OS Lite
   на microSD-карту (Raspberry Pi Imager, headless-настройка SSH)
2. **[02-setup-print-server.md](02-setup-print-server.md)** — настройка
   принт-сервера: CUPS, foo2zjs, прошивка принтера, почему LJ1020 особенный
3. **[03-clients.md](03-clients.md)** — подключение клиентов:
   Windows, Android, Linux, macOS/iOS
4. **[04-troubleshooting.md](04-troubleshooting.md)** — диагностика
   и типовые проблемы (нет прошивки, не виден :631, мусор вместо печати)

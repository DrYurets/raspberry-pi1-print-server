# Шаг 2. Настройка принт-сервера на Raspberry Pi

## Почему HP 1020 — особый случай

LaserJet 1020 — host-based принтер без прошивки в постоянной памяти.
При **каждом включении** компьютер должен загрузить в него файл прошивки
(`sihp1020.dl`), иначе принтер молчит. Поэтому:

- ставим драйвер **foo2zjs** (единственный рабочий вариант для 1020;
  официальный hplip его не поддерживает)
- udev-правило из пакета автоматически загружает прошивку при включении
  принтера или подключении USB — это уже настроено в setup-скрипте
- печать по сети — через **CUPS** (IPP, порт 631) + **avahi** (автообнаружение)

## 2.1. Скопируйте скрипты на Pi

С компьютера, из каталога проекта:

```bash
scp -r scripts docs pi@printserver.local:~/
```

Или просто создайте файлы на Pi через `nano` и вставьте содержимое.

## 2.2. Запустите установку

На Pi:

```bash
cd ~/scripts
sudo bash setup-print-server.sh
```

Скрипт сделает всё сам (см. комментарии в его шапке). На Pi 1
`apt install` идёт медленно — нормально, ждите.

> Во время установки принтер лучше **выключить**. После окончания
> скрипта включите его — прошивка загрузится автоматически,
> индикатор мигнёт оранжевым ~5 секунд.

Если принтер уже был включён — скрипт загрузит прошивку сам на шаге 5.

## 2.3. Проверка

```bash
# принтер в системе:
lpstat -t
# пробная страница:
lp -d HP1020 /usr/share/cups/data/testprint
```

Веб-интерфейс CUPS (опционально): `http://printserver.local:631`
в браузере с любого устройства в сети.

## 2.4. Полезные мелочи

- **IP принт-сервера.** Проще всего зарезервировать IP за MAC-адресом Pi
  в настройках роутера (DHCP reservation). Либо статический IP:
  `sudo nmtui` → Edit a connection.
- **Освободить ~48 МБ ОЗУ:** в `/boot/firmware/config.txt` добавить
  `gpu_mem=16` (на Lite GPU не нужен) и перезагрузиться.
- **Если Pi перезагрузился, а принтер был включён** — прошивка загрузится
  при старте udev автоматически. Если принтер включили позже — тоже сама.
  Ручная загрузка: `sudo bash load-firmware.sh`.

# Шаг 3. Подключение клиентов к принтеру

Принтер доступен по адресу:

```
http://printserver.local:631/printers/HP1020
```

(вместо `printserver.local` можно IP-адрес Pi, если mDNS не работает —
например `http://192.168.1.50:631/printers/HP1020`)

## Windows 10 / 11

1. **Параметры → Bluetooth и устройства → Принтеры и сканеры →
   Добавить устройство**
2. Подождите поиска, затем выберите **«Добавить вручную»** →
   **«Выбрать общий принтер по имени»** и введите:

   ```
   http://printserver.local:631/printers/HP1020
   ```

3. При выборе драйвера нужен **PostScript-драйвер** — CUPS на Pi
   сам растрирует документ в формат принтера. Подойдёт:
   - `Microsoft` → **Microsoft PS Class Driver**, или
   - `Generic` → **MS Publisher Imagesetter**

4. Напечатайте пробную страницу.

> Почему не родной драйвер HP 1020? Драйвер от HP работает только с
> «своим» портом (USB/9100). При печати через IPP Windows отправляет
> в CUPS то, что сгенерировал драйвер — PostScript отлично конвертируется
> на стороне Pi.

## Android

Вариант А — штатная служба печати (Android 8+):

1. **Настройки → Подключенные устройства → Настройки подключения →
   Печать → Служба печати по умолчанию** — включите.
2. Принтер должен появиться сам (mDNS-анонс через avahi). Если нет —
   вариант Б.

Вариант Б — **Mopria Print Service** из Play Market:
установите, откройте в Настройки → Печать — принтер найдётся по IPP.

Печать: в приложении `⋮ → Печать`.

## Linux (десктоп)

Принтер виден автоматически в настройках печати GNOME/KDE
(cherez mDNS), если на клиенте стоят `avahi-daemon` и `cups` — обычно есть.

Вручную из терминала:

```bash
lpadmin -p HP1020 -E -v ipp://printserver.local:631/printers/HP1020 -m everywhere
```

`-m everywhere` = IPP Everywhere: клиент спросит у Pi возможности
принтера и настроится сам.
